## 播放条 / 播放页统一（2026-10-25）

一条 bar 同时承担收起态与展开态的底部控制；播放页是浮层（`position: fixed`，z-index 46 > bar 45），
封面与歌名用 Web Animations 的共享元素动画在 bar 与播放页之间往返。

实测（1322×860，逐帧采样）：

- 展开：封面 `44px@(22,800)` → `119 → 248 → 296 → 314 → 320px@(153,248)`，约 380–400ms 到位。
- 收起：`235 → 116 → 68 → 50 → 44px@(22,800)`，约 420ms 后播放页卸载。
- 中断展开不会残留两个播放按钮：bar 的「展开/收起」在两种状态下是同一个 DOM 节点。

## 队列抽屉动画（同日）

- 开：`opacity 0 → 0.42 → 0.71 → 0.94 → 1`（`queue-panel-in` 260ms），内容层延迟 50ms 淡入。
- 收：`0.99 → 0.76 → 0.47 → 0.12`（`queue-panel-out` 200ms），动画结束后才卸载。
- 用 CSS keyframes 而非 transition：开的时候必须自带起手帧，不能依赖「先渲染一帧再切类名」
  ——窗口被遮挡时 `requestAnimationFrame` 会被节流到几百毫秒，靠它等帧的动画会直接不播。
- 不给每一行加入场动画：行以「曲目 id + 队列序号」为 key，序号一变就重挂，
  逐行动画会让跳转/移除时整列闪一下。

## 打包与安装

- `npm run dist:win` → `release/win-x64/huawei-music-desktop-0.1.0-win-x64-setup-unofficial.exe`。
- 未签名：首次运行会被 SmartScreen 拦一次；不提供自动更新。
- 安装包版 userData 是 `%APPDATA%\huawei-music-desktop`（按 `package.json` 的 `name`，不是 `productName`）。
- 安装后从 `华为音乐（非官方）.exe` 的版本资源里能读到 FileVersion / ProductVersion = 0.1.0。
